- **Hamburger menu** was the highest-priority item — the nav links visibly crowd the header on sub-400px viewports, which affects the core mobile experience.

- **Analytics** was filed as medium priority — it's not visible to users but is important for the owner to measure the portfolio's effectiveness. The existing Axiom integration makes this relatively low-effort to implement.
- All three issues were tagged with the `enhancement` label on GitHub.
